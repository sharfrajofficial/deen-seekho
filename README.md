# Deen Seekho (दीन सीखो)

> "Deen ko aasaan tareeqe se seekhiye" / "दीन को आसान तरीके से सीखिए"

A complete, responsive Islamic educational web application built with React, Tailwind CSS, Lucide icons, and modern interactive modules.

## Features
- **Alif-Ba Alphabet System (28 Letters)** with 4 joining forms (Isolated, Initial, Medial, Final), Hindi/Roman pronunciation guide, and interactive stroke tracing canvas.
- **Harakat Module & Interactive Letter Joining** workbench.
- **Step-by-Step Namaz Guide** with 5 Daily Prayers breakdown (Rak'ah, Farz, Sunnah) and scholarly difference disclosures.
- **Wuzu & Ghusl Guides** with Farz vs Sunnah categorizations.
- **10 Short Surahs, 6 Kalmas & Durood Sharif** with verified citations.
- **30 Masnoon Daily Duas** with category search.
- **Tactile Digital Tasbih** with sound & haptic vibration support.
- **Content Safety & Verification Protocols**: Source badges, error reporting, and LocalStorage progress persistence.

## How to Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Deploy Directly to Vercel / Netlify
1. Push this folder to GitHub.
2. Link your repository to [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
3. Build command: `npm run build` | Output directory: `dist`.
