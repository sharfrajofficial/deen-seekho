# deen-seekho
Yeh "Deen Seekho" (दीन सीखो) project ka ek complete, modern aur interactive Islamic educational web application package hai, jise beginners, bachhon aur badon ke aasaan deeni seekh ke liye design kiya gaya hai. Iska core maqsad Quranic Arabic, buniyadi ibadat aur rozmarrah ke deeni amoor ko ek trustworthy, clean aur accessible platform par lana hai
Yeh application modern frontend tech-stack jaise React, Tailwind CSS, Vite aur Lucide Icons par taiyar kiya gaya hai.
Iski design theme shant aur spiritual feel deti hai, jisme Deep Emerald Green, Warm Gold aur Cream colors ka behtareen istemal hua hai. 
Layout poori tarah responsive hai, jo mobile aur desktop dono par smooth experience deta hai.  
Project ke mukhya features aur modules:Alif-Ba Alphabet Module: Isme Alif se lekar Yaa tak pure 28 Arabic huroof shamil hain. Har harf ke saath uska Arabic text, Devanagari Hindi talaffuz, Roman script aur beginners ke liye makhraj (pronunciation points) diye gaye hain. Saath hi har harf ke 4 joining forms (Isolated, Initial, Medial, Final) ka interactive table maujood hai. 
Harakat aur Huroof Jodna: Zabar, Zer, Pesh, Jazm (Sukoon), Tashdeed aur Tanween ke buniyadi qawaid misalon ke saath samjhaye gaye hain. 
Mukammal Namaz Guide: Isme 5 waqt ki namazon ka detailed rakat chart (Farz, Sunnah, Nafl, Witr) diya gaya hai. Step-by-step Niyyah, Takbeer, Sana, Ruku, Qauma, Sajdah, Tashahhud aur Salam ko Arabic matn, transliteration aur Hindi tarjume ke saath explain kiya gaya hai.
Wuzu aur Ghusl: Wuzu ke 4 Faraiz, Ghusl ke 3 Faraiz aur masnoon duaon ko sahih references ke saath darj kiya gaya hai.   
Short Surahs & Kalmas: Surah Al-Fatiha samet aakhiri chhoti Surtein aur 6 Kalme mutafaq alaih ahadees aur quranic hawale ke saath diye gaye hain.   
Masnoon Duas & Smart Tasbih: Rozmarrah ki ahem duayein aur click sound/vibration support ke saath ek digital tasbih counter shamil hai
