# deen-seekho
Yeh "Deen Seekho" (दीन सीखो) project ka ek complete, modern aur interactive Islamic educational web application package hai, jise beginners, bachhon aur badon ke aasaan deeni seekh ke liye design kiya gaya hai. Iska core maqsad Quranic Arabic, buniyadi ibadat aur rozmarrah ke deeni amoor ko ek trustworthy, clean aur accessible platform par lana hai
